# SADC Tourism Management System (Python OOP)

## Overview
A Python object-oriented tourism booking system designed for Southern African Development Community (SADC) itineraries. It models seasonal pricing, capacity management, package validation, and the full booking lifecycle. The project demonstrates skills in OOP, business process modeling, and workflow automation.

## Tools & Technologies
- Python (object-oriented programming, data structures)
- Jupyter Notebook (system design and demo usage)
- GitHub + VS Code (version control, reproducible workflows)
- Business concepts (pricing, capacity, booking lifecycle)

## Key Features
- Country-aware seasonal pricing (month → season → multiplier)
- Experience categories (Safari, Beach, Cultural, Adventure) with price adjustments
- Per-date availability and capacity reservation
- Itinerary packages with discounts and validation rules
- Booking lifecycle: preview → confirm (reserve seats) → cancel (restore seats)

## Business Value
This system shows how Python can be used to model real-world tourism operations. It highlights your ability to design scalable systems that handle pricing, availability, and booking workflows — skills relevant to Data Analyst, Business Analyst, and Junior Data Engineer roles.
